# medihalal-rules

Public auto-update feed for the MediHalal app (ingredient halal/haram rules + sources).

- `meta.json` — sha256 + size + updated timestamp of `rules.json`
- `rules.json` — deterministic rules; every rule cites a published halal-authority document

Generated by `scripts/publish_rules.py` in the (private) MediHalal app repo. Do not edit by hand.
